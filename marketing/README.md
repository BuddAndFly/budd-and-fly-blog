# Kit marketing Budd&Fly

## Pinterest : `pinterest-epingles.csv`

167 épingles, une par guide publié (hors destinations déconseillées).
- Image verticale 1000×1500 générée automatiquement à chaque déploiement : `https://buddandfly.com/og/<pays>-pin.jpg`.
- Lien vers le guide, avec un suivi `utm_source=pinterest` (visible dans l'outil d'audience une fois installé).
- Un tableau par continent : « Guides de voyage gratuits – Europe », etc.

Mise en ligne :
1. Créer un compte **Pinterest Business** (gratuit) au nom de Budd&Fly et revendiquer le site buddandfly.com (Paramètres → Comptes revendiqués → Sites web : Pinterest donne une balise meta, me l'envoyer pour que je l'ajoute).
2. Créer les tableaux (noms exacts de la colonne « Pinterest board »), ou laisser l'import les créer.
3. Créer → **Créer des épingles en masse** → importer le fichier CSV.
4. Conseil : étaler la publication (5 à 10 épingles par jour) en remplissant la colonne « Publish date » plutôt que tout publier d'un coup.
